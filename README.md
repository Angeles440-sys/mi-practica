# Mi Proyecto Integrador Full Stack

> Una aplicación web moderna para la gestión eficiente de inventarios y usuarios en tiempo real.

---

## 📌 Descripción del Proyecto

**Mi Proyecto Integrador** es una solución web orientada a pequeñas y medianas empresas que buscan optimizar su control de inventario. Permite registrar productos, categorizarlos y monitorear el stock en tiempo real mediante un panel intuitivo y seguro.

Este repositorio actúa como la **carta de presentación profesional** de la arquitectura del proyecto, demostrando la integración limpia entre el *frontend* y el *backend*.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (ES6+), React.js
- **Backend:** Node.js, Express.js
- **Base de Datos:** MongoDB
- **Control de Versiones:** Git, GitHub
- **Automatización CI/CD:** GitHub Actions
